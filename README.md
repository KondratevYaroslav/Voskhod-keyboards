# Восход Клавиатуры — прошивки и раскладки

Прошивки, Vial-раскладки и инструкции для сплит-клавиатур бренда **Восход Клавиатуры**.

## Модели

- **Corne** — [Прошивки/Corne](Прошивки/Corne)
- **Sofle** — [Прошивки/Sofle](Прошивки/Sofle)
- **Lily58** — [Прошивки/Lily58](Прошивки/Lily58)

В папке каждой модели:
- `README.md` — как прошить клавиатуру и как загрузить раскладку через Vial
- `*.uf2` — актуальная прошивка (отдельно для левой и правой половины)
- `*.vil` — раскладка по умолчанию для Vial
- `Архив/` — старые версии прошивки

## Что нового

Список изменений между версиями прошивки — в [CHANGELOG.md](CHANGELOG.md).

## Исходный код

Прошивки основаны на [vial-qmk](https://github.com/vial-kb/vial-qmk) (лицензия GPL). Исходный код наших изменений — в отдельном репозитории [voskhod-vial-qmk](https://github.com/Voskhod-keyboard/voskhod-vial-qmk): там же лежат тексты лицензии и инструкция по самостоятельной сборке.
