# Восход Клавиатуры Corne — прошивка и раскладка

## Прошивка

1. Подключите левую половинку клавиатуры к ПК.
2. Дважды нажмите кнопку **RESET**, расположенную под защитным стеклом.
3. В открывшуюся папку скопируйте файл прошивки левой половинки — `corne_voskhod_left_v2.uf2`. После копирования папка автоматически закроется, половинка перезагрузится.
4. Повторите процедуру с правой половинкой и файлом `corne_voskhod_right_v2.uf2`.

Старые версии прошивки — в папке `Архив`.

## Раскладка (Vial)

1. Скачайте и установите приложение VIAL с официального [сайта](https://get.vial.today/).
2. Запустите приложение VIAL, убедитесь, что ваша клавиатура отобразилась на основном экране. При необходимости выберите клавиатуру из выпадающего списка.
3. Нажмите меню **File** → **Load saved layout** и выберите файл `voskhod_corne.vil`.
4. На основном экране отобразится новое расположение клавиш.
5. Клавиатура готова к работе.
