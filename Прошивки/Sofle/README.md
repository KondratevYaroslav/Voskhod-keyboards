# Восход Sofle — прошивка

## Процедура прошивки

1. Подключите левую половинку клавиатуры к ПК.
2. Дважды нажмите кнопку **RESET**, расположенную под защитным стеклом.
3. В открывшуюся папку скопируйте файл прошивки левой половинки — `sofle_voskhod_left_v2.uf2`. После копирования папка автоматически закроется, половинка перезагрузится.
4. Повторите процедуру с правой половинкой и файлом `sofle_voskhod_right_v2.uf2`.

Старые версии прошивки — в папке `Архив`.
